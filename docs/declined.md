# 已拒绝的方案

记录评估过但**决定不做**的事及理由，避免重复讨论。

## no-mistakes（本地 push 门禁）

- 评估日期：2026-11-15；版本 v1.106.1 实测一轮（review/test 通过，document 阶段因输出格式失败，全程约 45 分钟）。
- 结论：**不采用**。理由：本地门可绕过；与 AgentGate 的检查重复；每轮多一次模型调用与 token 预算冲突；试跑耗时远超收益。
- 替代：AI 审查已由 AgentGate 的 `ai_review` 统一承担；PR 描述由 `new_pr.py` 一次成型。
- 例外：保留二进制，想再试可随时手动使用，但不得接入自动化流程。

## push 即自动开 PR

- 评估日期：2026-11-15。
- 结论：**不做**。每个 WIP push 都会触发 CI（约 4.5 分钟）与 AI 审查（token），成本与价值倒挂。
- 替代：送审时用 `new_pr.py` 一条命令生成合规描述并开 PR。
